# TradeOps ERP 实施与运行手册

## 1. 上线前检查

- 与销售、运营、客服、风控确认字段定义和状态迁移。
- 确认每条 P0 需求有负责人、目标版本和验收标准。
- 准备 PostgreSQL、环境变量、反向代理和 TLS。
- 配置管理员令牌；正式环境改为企业 SSO/RBAC。
- 使用合成数据完成验收，不导入未脱敏数据。

## 2. 第三方对接清单

| 系统 | 对接方式 | 关键约定 | 降级策略 |
| --- | --- | --- | --- |
| TunTunAgent / Dify | Workflow API | 结构化意图、预算、线索来源 | 回退规则分类和人工跟进 |
| 商品账号服务 | REST API | SKU 唯一、幂等键、库存状态 | 失败任务重试，不释放锁定库存 |
| 支付平台 | 签名 Webhook | 支付单号唯一、可重放 | 进入人工对账队列 |
| 企业通知 | Bot Webhook | 通知 ID 幂等 | 补发，不回滚订单主事务 |

## 3. 发布步骤

1. 备份数据库并验证恢复命令。
2. 在预发布环境执行迁移和 18 项回归测试。
3. 加载合成验收数据，按 AC-01 至 AC-08 走查。
4. 灰度开放只读看板，再开放订单和审批写操作。
5. 观察错误率、积压任务和审批处理时长。
6. 发布后 24 小时复盘问题，进入需求中心排期。

## 4. 故障分级

| 等级 | 示例 | 处置 |
| --- | --- | --- |
| P0 | 库存重复分配、错误退款 | 立即停止相关写操作，保留审计，人工核对 |
| P1 | 支付通知积压、履约失败 | 启用重放/人工队列，30 分钟内定位 |
| P2 | AI 分类不可用、通知失败 | 回退规则与人工处理，不阻断订单主链 |

## 5. 监控项

- API 5xx、P95 延迟、数据库连接与磁盘空间。
- 幂等冲突数、库存锁定失败数、待履约订单数。
- 待审批数量与处理时长、退款金额分布。
- Webhook 成功率、积压、重试次数和终态失败。
- 各模块活跃用户、动作数、错误数和平均处理时长。

## 6. 回滚原则

- 应用版本可以回滚，已提交的业务状态不得靠代码回滚覆盖。
- 数据纠正必须通过补偿动作并写入审计。
- AI Prompt/模型切换与业务规则发布分开，避免同时变化导致无法归因。
