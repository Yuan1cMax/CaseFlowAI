# TradeOps ERP 培训与上线计划

## 培训分组

| 受众 | 内容 | 实操验收 |
| --- | --- | --- |
| 销售 | 线索跟进、转客户、新建订单 | 独立完成低风险下单 |
| 运营 | 库存状态、履约交付、异常暂停 | 能解释每个库存状态的进入条件 |
| 客服 | 建工单、查看订单上下文、使用 SOP | 不在审批前承诺退款金额 |
| 风控/主管 | 审批依据、驳回后果、审计查询 | 完成批准和驳回两条路径 |
| 系统运营 | 集成监控、重试、问题上报 | 能按故障等级启动对应预案 |

## 推广节奏

1. 角色访谈和现状流程确认。
2. 用合成数据开展关键用户培训。
3. 只读看板灰度，收集字段和口径问题。
4. 开放订单、履约与审批，安排上线值守。
5. 上线一周复盘使用率、异常率和处理时长。
6. 改进项进入需求中心，按价值和风险重新排序。

## 运营机制

- 每日：查看待审批、待履约和集成积压。
- 每周：输出模块使用、流程瓶颈和改进动作。
- 每版本：发布说明、角色化培训、回归验收和变更复盘。
- 每月：复核 SOP、风险规则和低使用功能，决定优化或下线。
